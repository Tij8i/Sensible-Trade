## Structure

- Jekyll-based static site
- Hosted on GitHub Pages
- Single-page design with anchor navigation

## Sections

- Hero: Main value proposition
- What We Do: Product Sourcing, Export & Compliance, Logistics
- Who We Work With: Target customer segments
- Why Work With Us: Value proposition + Italy map
- Our Services: 4-column service overview
- Contact: Lead capture form

## Images Needed

Upload to `assets/img/`:
- `hero-olives.jpg` — Hero background (olives in container)
- `pizza.jpg` — "Who we work with" section image

## Development

```bash
bundle install
bundle exec jekyll serve
```

## Enable GitHub Pages

1. Go to Settings → Pages
2. Source: Deploy from branch
3. Branch: main
4. Save

Site will be live at: https://sensibletrade.au
